## ⚠️ زنجیرهٔ تعویض — کاندید B-3 (تأییدنشده، نیازمند بررسی)

گام ۱: فروش ۱۰۰٬۰۰۰ → تعویض با ۱۵۰٬۰۰۰ (diff=۵۰٬۰۰۰، `CASH`، `returnId=۱`، `invoiceId=۱`)

سپس بررسی فاکتور مقصد:
```
items = [{ id:1, variantId:1, qty:1, price:100000 }]
```
یعنی فاکتورِ برگشتی از تعویض، **کالای جایگزین ۱۵۰٬۰۰۰ را ندارد** و همان فاکتور اصلی (id=۱)
با همان کالای قدیمی است.

گام ۲: تعویض دوباره روی `invoiceId` بازگشتی ⇒ رد شد:
«تعداد برگشتی برای پیش‌نمایش از باقی‌ماندهٔ مجاز بیشتر است.»

**تفسیر احتمالی:** یا (الف) تعویض، فاکتور فرزند با کالای جایگزین نمی‌سازد و در نتیجه
زنجیرهٔ تعویض عملاً ممکن نیست؛ یا (ب) شناسهٔ فاکتور فرزند در فیلد دیگری از خروجی است و من
اشتباه خواندم. **تأییدنشده** — نیاز به بررسی شکل خروجی `createExchange` و ساختار
فاکتور جایگزین دارد.
