# پرامپت کوتاه برای بازبینی کلاد (یک‌بار، بعد از فاز ۶)

> این را با آدرس آرشیو پین‌شده به کلاد بده. خودکفاست: هر چه لازم است داخل زیپ است.

---

پروژه «محک» (Electron + React + Prisma/SQLite، فارسی/RTL) را در آرشیو پین‌شده‌ای
که همراه همین پیام می‌آید باز کن و **فقط بازبینی کن، کد ننویس**:

(اگر لینک آرشیو نبود، همین شاخه را بگیر: `arena/01a10787-mahmah`.)

داخل آرشیو، این‌ها را بخوان (به همین ترتیب):

1. `_تحویل/طرح-چاپ-v3.md` — طرح مرجع (بخش ۸.۱–۸.۳، ۱۰، ۱۱، ۱۲).
2. `_تحویل/گزارش-نشست۲۲۲-فاز۰-چاپ.md` تا `…فاز۶-چاپ.md` (+ گزارش رفع بازبینی فاز ۰).
3. `_تحویل/TESTLOG-فاز۵-تا۶-چاپ.txt` — رگرسیون کامل: typecheck، نگهبان‌ها،
   همه‌ی فایل‌های تست، esbuild، بسته‌بندی.

هدف: پیدا‌کردن باگ‌های **واقعی** در پیاده‌سازی فازهای ۰ تا ۶ (اندازه‌ی فاکتور،
لیبل ردیفی، resolver چاپگر، چاپ آزمایشی/پیش‌نمایش، مسیر خام RAW، بقیه‌ی چاپ‌ها).

قواعد بازبینی:

* فقط یافته‌ای گزارش کن که **مسیر اجرا** داشته باشد: باگ با مسیر بازتولید،
  ناسازگاری با طرح، یا نقض یکی از قراردادهای `DECISIONS.md`.
* باگ‌های تخیلی، سلیقه‌ای و «می‌شد بهتر بود» را جدا و در انتها بنویس (یا
  اصلاً ننویس). فقط critical/medium.
* برای هر باگ: فایل/تابع، مسیر اجرا، چرا باگ است، و **کوچک‌ترین اصلاح پیشنهادی**.
* این قراردادها غیرقابل‌مذاکره‌اند (هر تغییری که نقضشان کند رد است): لغو = خطای
  قطعی و بدون تغییر شمارنده؛ timeout/crash/بسته‌شدن پنجره = `PrintOutcomeUnknownError`
  و بدون retry خودکار؛ هیچ fallback خودکار به چاپگر دیگر یا موتور دیگر؛
  گیت `printEnabled`/`posPrintToggle`؛
  ماژول‌های گزارش فروش، بستن صندوق و گزارش‌های مدیر **دست‌نخورده**.
* هیچ تستی ضعیف یا حذف نشده باشد؛ اگر تستی عوض شده، دلیلش باید در گزارش فاز
  باشد (فهرست سه تست ساختاری در گزارش فاز ۵ §۵ آمده است).
* مسیر RAW روی سخت‌افزار آزمون نشده است؛ سه مجهول TSPL (عرض `SIZE`، قطبیت بیت،
  `DIRECTION`) عمداً حدس زده نشده‌اند — این‌ها را به‌عنوان «آزمون مالک» بپذیر،
  نه باگ.

اجرای سریع (اختیاری، برای دیدن سبزی):

```
npm ci --ignore-scripts --no-audit --no-fund
node --import ./test/harness/register.mjs tests/audit-fixes/fix-s222-print-phase5-raw.mjs
node --import ./test/harness/register.mjs tests/audit-fixes/fix-s222-print-phase6-remaining-prints.mjs
npx tsc --noEmit        # ۶۱۱ خطای ازقبل‌موجود؛ مجموعه‌ی خطاها نباید عوض شده باشد
```

خروجی مطلوب: فهرست کوتاه باگ‌های critical/medium + برای هرکدام کوچک‌ترین اصلاح.
