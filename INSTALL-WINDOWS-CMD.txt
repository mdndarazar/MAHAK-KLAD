MAHAK-KLAD — نصب و اجرای نسخهٔ سورس در Windows CMD
=================================================

این ZIP سورس پروژه است، نه فایل نصب‌کنندهٔ آماده و نه بستهٔ آفلاین.
برای نصب نخست به اینترنت نیاز است تا npm و Prisma وابستگی‌های برنامه را دریافت کنند.

پیش‌نیازها
----------
- Windows 10/11 نسخهٔ 64 بیتی
- Node.js نسخهٔ 22 LTS یا جدیدتر (x64)
- اتصال اینترنت در اجرای نخست

استخراج و اجرای برنامه
----------------------
۱) ZIP را، ترجیحاً در مسیر کوتاهی مثل C:\MAHAK-KLAD، استخراج کنید.
۲) CMD را باز کنید و فرمان‌ها را به‌ترتیب اجرا کنید:

    cd /d C:\MAHAK-KLAD
    node --version
    npm --version
    npm ci
    npm run db:generate
    npm run dev

پس از اجرای فرمان آخر، برنامهٔ دسکتاپ باز می‌شود. برای اجرای دوباره، از همان پوشه
فقط این دو فرمان آخر را اجرا کنید:

    npm run db:generate
    npm run dev

ساخت نصب‌کنندهٔ مستقل ویندوز
----------------------------
اگر نصب مستقل (EXE) می‌خواهید، پس از نصب پیش‌نیازها و وابستگی‌ها اجرا کنید:

    cd /d C:\MAHAK-KLAD
    npm run dist:win

در صورت موفقیت، نصب‌کنندهٔ Windows x64 در پوشهٔ dist ساخته می‌شود.
ساخت EXE به دانلود وابستگی‌ها و اجزای لازم Electron/Prisma نیاز دارد.

بررسی سورس
----------
    npm run check:syntax
    npm run build:check

نکتهٔ مهم
---------
پیش از جایگزین‌کردن نصب قبلی، از داده‌های برنامه نسخهٔ پشتیبان بگیرید.
این ZIP شامل فایل EXE آماده نیست و بدون اینترنت برای نصب نخست کافی نیست.
