# دستهٔ ۲۴ — اولترا تک‌مرحله‌ایِ آبشار (۱٫۵ میلیونی + تعویضِ دوطرفه + چک)

**شعار این دسته:** «سخت‌ترین فاکتورِ ممکن، ولی فقط یک برگشت و یک تعویض — زنجیره نه، عمقِ یک مرحله.»

> **تشبیه:** مشتری سبدِ ۷قلمیِ ۱٫۵ میلیونی می‌خرد: ۱۵۰ نقد + ۱۵۰ کارت + ۳×۱۰۰ اعتبار + چکِ ۳۰۰ + نسیهٔ ۶۰۰ (B=۹۰۰k با چک داخلش). ما در همین **یک مرحله** همهٔ آبشار را تست کردیم: بدهیِ تنها، بدهی+اعتبار+نقد+چک، تعویضِ مثبتِ بزرگ و تعویضِ منفیِ بدهی‌خور، و هر سه وضعیتِ چک (PENDING/BOUNCED/CLEARED) با قانونِ «مبلغِ دقیق».

**نتیجه:** **۰ باگ — تمامِ گام‌ها با عددِ دقیق و اتمیک بودنِ چک درست بود.**

دادهٔ خام: `batch-030-waterfall-ultra-single.jsonl` — ۱۳ ردیف
