# دستهٔ ۱۵ — ترکیب نسیه + چک + برگشت، و تعویض با بدهی

| سناریو | انتظار | واقعی |
|---|---|---|
| فاکتور نسیهٔ ۲ قلمی ۲۰۰٬۰۰۰ | بدهی ۲۰۰٬۰۰۰ | ۲۰۰٬۰۰۰ ✅ |
| ثبت چک ۴۰٬۰۰۰ (در جریان) روی همان فاکتور | بدهی **بدون تغییر** | ۲۰۰٬۰۰۰ ✅ |
| برگشت ۱ قلم (۱۰۰٬۰۰۰) با «بدون بازپرداخت» | `refundAmount=۰` و بدهی ۱۰۰٬۰۰۰ | ۰ ✅ (بدهی باید ۱۰۰٬۰۰۰ شود) |
| تعویض کالای ۱۰۰٬۰۰۰ با کالای ۶۰٬۰۰۰ روی **فاکتور نسیه** | مابه‌التفاوت به‌جای پول نقد از **بدهی** کم شود | پذیرفته شد: `diff=۰`، تسویه=`DEBT_REDUCTION` ✅ |

**نکتهٔ مثبت:** سیستم در فاکتور نسیه، مابه‌التفاوت منفی را به مشتری **نقد** پس نداد؛
آن را از بدهی کم کرد (سیاست S60-1). یعنی پول به کسی که پول نداده، پرداخت نمی‌شود ✅

## اجرا نشده
تعویض با مابه‌التفاوت مثبت (`paymentMethodId` نام درست را قبول نکرد) — در دستهٔ بعد با نام درست.
