# دستهٔ ۹ — محدودیت «فقط این کالا / این دسته» در ماژول کد اعتباری (اجرا نشد)

**کد:** `2a61a5a`

## چه تلاش شد
صدور اعتبار از **مسیر ماژول** (`storeCreditService.issueManual`) با
`restrictScope: 'VARIANT' | 'CATEGORY' | 'ALL'` و سپس مصرف روی کالای مجاز/غیرمجاز.

## چه شد (سه مانع به‌ترتیب)
1. بدون رمز: «صدور دستی اعتبار خرید همیشه رمز می‌خواهد…» ✅ گیت امنیتی سالم است.
2. با رمز مدیر: خطای `Provided value cannot be bound to SQLite parameter 1`
   ⇒ **محدودیت هارنس تست پروژه** (استاب SQLite نمی‌تواند یکی از مقادیر ورودی
   `issueManual` را bind کند)، نه خطای محصول.
3. بنابراین **هیچ‌کدام از پنج سناریوی محدوده اجرا نشد**.

## نتیجهٔ صادقانه
- تست C-4 دستهٔ ۸ (مصرف بارکد محدود به کالای دیگر) **معتبر نیست**، چون محدودیت را با
  `UPDATE` مستقیم ست کرده بودم، نه از مسیر ماژول. آن مورد را هم **باگ اعلام نمی‌کنم**.
- برای تست واقعی این موضوع، اول باید هارنس (یا یک اسکریپت با `prisma` واقعی) بتواند
  `issueManual` را اجرا کند؛ سپس پنج سناریو تکرار شود.
