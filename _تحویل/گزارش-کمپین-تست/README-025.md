| **hell30-sale** | فاکتورِ ۳۰قلمی با ۳ تعدادِ متغیر + تخفیفِ قلمی + ۸ اعتبارِ هم‌زمان + چک + برگشتِ ۵ قلم | سقفِ اعتبار (۸تا)، سهمِ هر اعتبار ۴۰/چند، موجودیِ منفیِ مجاز، بدهیِ باقی‌مانده | PASS |

| **hell-return-overqty** | خریدِ ۲ قلم، برگشتِ ۵ قلم | «از قابلِ برگشت بیشتر است — حتی با تاییدِ مدیر نه» | REJECTِ درست |

| **hell-wholesale500** | ۵۰۰ قلمِ ۱۰k = ۵M عمده | قیمتِ مرجعِ هر واریانت ۱ ریال بیشتر → «قیمت کمتر از مرجع — رمزِ مدیر لازم» | REJECTِ درست (۱۰۰ مورد) |
| **hell-exchange-pos** | ۲۰۰k → ۴۰۰k (+۲۰۰k) | مابه‌التفاوتِ مثبت فقط از نقدِ واقعی | PASS |
| **hell-waterfall** | ۱٫۵M با ۷ قلم + نقد۱۵۰+کارت۱۵۰+۳×اعتبار۱۰۰+چک۳۰۰ → برگشتِ ۶ قلم | آبشارِ کاملِ `B→اعتبار→چک→نقد` | PASS |
