MAHAK-KLAD — راهنمای اجرای سورس در Windows CMD
================================================

این ZIP بستهٔ سورس پروژه است، نه فایل EXE آماده و نه بستهٔ آفلاین.
برای نصب نخست به اینترنت نیاز دارید تا npm و Prisma وابستگی‌های برنامه را دریافت کنند.

پیش‌نیازها
----------
- Windows 10 یا 11، نسخهٔ 64 بیتی
- Node.js نسخهٔ 22 LTS یا جدیدتر (x64)
- اتصال اینترنت در اجرای نخست

استخراج و اجرا
-------------
۱) ZIP را در مسیری کوتاه، مثلاً C:\MAHAK-KLAD، استخراج کنید.
۲) CMD را باز کنید و این فرمان‌ها را به‌ترتیب اجرا کنید:

    cd /d C:\MAHAK-KLAD
    node --version
    npm --version
    npm ci
    npm run db:generate
    npm run dev

فرمان آخر برنامهٔ دسکتاپ را باز می‌کند؛ هنگام اجرا CMD را نبندید. برای توقف Ctrl+C بزنید.
برای اجرای دوباره، در پوشهٔ پروژه اجرا کنید:

    npm run db:generate
    npm run dev

ساخت نصب‌کنندهٔ مستقل Windows x64
---------------------------------
پس از نصب موفق وابستگی‌ها، اجرا کنید:

    cd /d C:\MAHAK-KLAD
    npm run dist:win

در صورت موفقیت، EXE در پوشهٔ dist ساخته می‌شود. ساخت آن نیز به دانلود وابستگی‌های لازم نیاز دارد.

بررسی سریع
----------
    npm run check:syntax
    npm run build:check

پیش از جایگزینی نصب موجود، از داده‌های کاری برنامه نسخهٔ پشتیبان بگیرید.
