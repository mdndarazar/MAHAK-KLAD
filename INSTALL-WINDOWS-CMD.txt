MAHAK-KLAD — راهنمای سورس برای Windows CMD
============================================

این نسخه برای آزمون ویندوز و گوشی شما آماده است. تست‌های خودکار CI ویندوز
گیت‌هاب و ساخت نصب‌کننده برای همین کد پاس شده‌اند، ولی هنوز روی ویندوز
نصب‌شدهٔ واقعی، گوشی یا تونل اجرا نشده است. کنترل از راه دور با گوشی در این
کد هست ولی پیش‌فرض خاموش است؛ تا خودتان آن را در «تنظیمات ← کنترل از راه دور
با گوشی» روشن نکنید، هیچ درگاه یا اتصالی باز نمی‌شود. تا آزمون‌های خودتان
(docs\REMOTE-USER-TEST.md) تمام نشده، آن را روی دادهٔ واقعی فروشگاه روشن
نکنید. وضعیت دقیق تست‌های همین نسخه در VERSION.txt و انتهای
docs\REMOTE-TODO.md آمده است.

ZIP سورس، فایل نصب‌کنندهٔ آمادهٔ EXE نیست. برای آماده‌سازی به اینترنت و
Windows 10/11 نسخهٔ ۶۴ بیتی و Node.js نسخهٔ 24 x64 نیاز است.

۱) ZIP کامل را در پوشه‌ای تازه، مثلاً C:\MAHAK-KLAD، استخراج کنید. آن را روی
نصب قبلی کپی نکنید. پوشه باید package-lock.json و prisma\migrations را داشته باشد.

۲) CMD را باز کنید و مسیر را متناسب با پوشهٔ واقعی خودتان جایگزین کنید:

    cd /d "C:\MAHAK-KLAD"
    node --version
    npm --version
    SETUP-WINDOWS.cmd

این مرحله وابستگی‌ها را نصب و Prisma Client را تولید می‌کند؛ برنامه را اجرا یا
migration دیتابیس را اعمال نمی‌کند. اگر خطا دیدید، ادامه ندهید و متن خطا را نگه دارید.
هیچ دستوری برای حذف دیتابیس یا lockfile اجرا نکنید.

اجرای دسکتاپ از سورس
-------------------
هشدار: این اجرا از پوشهٔ دادهٔ موجود برنامه استفاده می‌کند و ممکن است migration
یا اصلاح داده انجام دهد. دیتابیس آزمایشی ایزوله نیست. ابتدا از داخل برنامهٔ
نصب‌شده نسخهٔ پشتیبان بگیرید و برنامهٔ دیگر را ببندید. اگر نمی‌خواهید به دادهٔ
موجود دست بخورد، این دستور را اجرا نکنید:

    RUN-WINDOWS.cmd

اسکریپت تأیید می‌گیرد. اگر DATABASE_URL یا فایل محیطی محلی مثل .env،
.env.local، .env.development، .env.development.local یا prisma\.env وجود داشته
باشد، برای جلوگیری از اختلاف مسیر دیتابیس متوقف می‌شود. هیچ فایل یا تنظیمی را
حذف نکنید؛ برای بررسی راهنمایی بخواهید.

کنترل از راه دور با گوشی در این حالت کار نمی‌کند. هاب کنترل از راه دور و Node
همراه آن فقط هنگام ساخت نصب‌کننده (BUILD-WINDOWS.cmd) در پوشهٔ resources\remote
برنامه گذاشته می‌شوند. اگر برنامه با RUN-WINDOWS.cmd باز شده باشد، صفحهٔ «کنترل
از راه دور با گوشی» پیام «فایل‌های لازم کنترل از راه دور در نصب یا پوشهٔ داده
پیدا نشد.» را نشان می‌دهد. برای آزمون کنترل از راه دور، نصب‌کننده را بسازید و
نصب کنید، پنجرهٔ RUN-WINDOWS.cmd را ببندید و نسخهٔ نصب‌شده را باز کنید.

ساخت نصب‌کنندهٔ ویندوز
----------------------
پس از آماده‌سازی:

    BUILD-WINDOWS.cmd

این دستور ابتدا typecheck می‌کند و فقط در صورت موفقیت نصب‌کنندهٔ x64 را با نام
dist\ArkaPOS Setup 0.1.0.exe می‌سازد (نام نمایشی تازه؛ نام exe همان MahakPOS.exe
و پوشهٔ داده همان می‌ماند). دو خطای قدیمی typecheck در SalesService.ts
در commit 7c557f2 رفع شده‌اند. نتیجهٔ CI ویندوز برای هر نسخه در انتهای
docs\REMOTE-TODO.md ثبت است. CI نصب‌کننده را با Node 22 می‌سازد. ساخت با Node 24
روی رایانهٔ واقعی مالک یک بار موفق بوده است (۲۰۲۶-۱۱-۲۰). اگر خطا دیدید، آن را دور
نزنید و متن خطا را نگه دارید. وجود پوشهٔ dist به‌تنهایی موفقیت ساخت جدید را ثابت
نمی‌کند.

نکته‌های ساخت روی رایانهٔ واقعی (از نخستین آزمون مالک، ۲۰۲۶-۱۱-۲۰):
- BUILD-WINDOWS.cmd را در cmd با دسترسی مدیر اجرا کنید: Start را بزنید، cmd را
  بنویسید، روی «Command Prompt» راست‌کلیک کنید و «Run as administrator» را بزنید.
  بدون دسترسی مدیر، ابزار ساخت هنگام باز کردن بستهٔ winCodeSign با خطای
  Cannot create symbolic link متوقف می‌شود.
- اگر ساخت با Packaging Node license is missing متوقف شد، علتش این است که
  نصب‌کنندهٔ رسمی Node فایل LICENSE را کنار node.exe نمی‌گذارد. این دستور را در
  همان cmd مدیر اجرا کنید و بعد BUILD-WINDOWS.cmd را دوباره بزنید. باید OK: چاپ
  کند؛ اگر FAILED چاپ کرد، با فیلترشکن دوباره امتحان کنید:

    node -e "const path=require('path'),fs=require('fs');const dest=path.join(path.dirname(process.execPath),'LICENSE');fetch('https://api.github.com/repos/nodejs/node/contents/LICENSE?ref='+process.version,{headers:{'Accept':'application/vnd.github.raw','User-Agent':'mahak-pos-build'}}).then(r=>{if(!r.ok)throw new Error('HTTP '+r.status);return r.text()}).then(t=>{if(!t.startsWith('Node.js is licensed for use as follows:'))throw new Error('unexpected content');fs.writeFileSync(dest,t);console.log('OK: '+dest)}).catch(e=>{console.error('FAILED: '+e.message);process.exit(1)})"

- از این نسخه، خود ساخت هم همین توضیح و همین دستور را (به فارسی و انگلیسی) چاپ می‌کند و با خطا می‌ایستد؛ چیزی را خودش دانلود نمی‌کند.
- نصب‌کننده را با دوبار کلیک در File Explorer اجرا کنید، نه از داخل cmd مدیر.
- مهم: نصب‌کننده‌ای که از سورس‌های پیش از اصلاح package.json (۲۰۲۶-۱۱-۲۰) ساخته
  شود، از جمله ZIP 118406a3، هنگام باز شدن خطای
  Cannot find module '.prisma/client/default' می‌دهد، چون کلاینت تولیدشدهٔ Prisma
  در بسته نبود. این اشکال با اجازهٔ مالک اصلاح شد؛ از سورس تازه استفاده کنید.

بررسی‌های جداگانهٔ سورس:

    npm run check:syntax
    npm run build:check

اینها جایگزین تست نصب، تست گوشی، صحت مالی یا آماده‌بودن کنترل از راه دور نیستند.

پیش از نصب نسخهٔ ArkaPOS روی رایانه‌ای که نسخهٔ قبلی دارد
-------------------------------------------------------
1) داخل برنامهٔ قبلی یک بکاپ بگیرید (تنظیمات ← بکاپ).
2) برنامه را کامل ببندید و از پوشهٔ داده کپی بگیرید:

    xcopy "%APPDATA%\mahak-pos" "%USERPROFILE%\Desktop\mahak-pos-copy\" /E /I /H /Y

3) پوشهٔ نصب و پوشهٔ داده را ببینید؛ در هر دو خروجی باید mahak-pos باشد:

    dir /b "%LOCALAPPDATA%\Programs" | findstr /i mahak
    dir /b "%APPDATA%" | findstr /i mahak

   اگر چیزی جز mahak-pos دیدید، نصب نکنید و خروجی را بفرستید.
4) سپس ArkaPOS Setup 0.1.0.exe را با دوبار کلیک اجرا کنید. پس از نصب: میان‌بر
   «ArkaPOS» با لوگو، عنوان پنجره «ArkaPOS» و فروش‌های قبلی سر جایشان باشند.
   اگر میان‌بر قدیمی «MahakPOS» هم ماند، همان برنامه را باز می‌کند و پاک‌کردنش
   بی‌خطر است.
