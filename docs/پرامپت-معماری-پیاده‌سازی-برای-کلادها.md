# طرح اپ موبایل کنترل از راه دور — MAHAK-KLAD
**تاریخ:** ۱۴۰۵/۰۸/۲۳ · **ZIP:** 87f4298d · **وضعیت:** فقط معماری — هیچ کدی تغییر نکرده

> تعریف مالک: عدد آبی = کشو+کارتخوان (شامل تسویه نسیه قدیمی).

**هدف:** مدیر با موبایل (هر موبایلی) گزارش لحظه‌ای + عدد مرجع کشو+کارتخوان + باز کردن هر قفل (نسیه فقط مثال) بدون دیدن رمز + خروج — حرفه‌ای و سبک.

**اصل:** هیچ مسیر فروش/برگشت/تعویض/چک/نسیه/تخفیف/صندوق/شیفت بازنویسی نشود — فقط API فقط-خواندنی + دستور قفل‌گشایی عمومی. فروشنده مثل الان با Electron.

**معماری ۳ لایه:** [Electron SQLite] ←→ [Cloud Postgres Fastify] ←→ [PWA] — Electron هر ۳۰ث snapshot، موبایل از ابر می‌خواند، دستور از موبایل→ابر→Electron.

**چند مدیره + دو مدل ورود (ایده مالک):** نامحسوس فقط-دیدن (فروشنده نمی‌فهمد) + مداخله با PIN دوم (لاگ). نقش‌ها OWNER (همه+دعوت/حذف/Panic)، MANAGER (فقط پنل‌های تیک‌خورده)، VIEWER (فقط دیدن). ۱ تا ۵ مدیر، دعوت لینک/QR ۱۰ کاراکتری یک‌بارمصرف ۴۸ساعته بدون پیامک (PENDING_OWNER_APPROVAL تا مالک تایید کند)، اتمی با advisory_lock + UNIQUE seat_no 1..5. کاتالوگ خودکار از LOCKED_PANELS با catalogHash — پنل جدید خودکار ظاهر می‌شود، پیش‌فرض فقط OWNER. view_scope جدا از approve_panels + presetها + tier NORMAL ۱۰دقیقه / SENSITIVE_MONEY ۵دقیقه. دو مدل ورود: نامحسوس هیچ ردی روی دسکتاپ ندارد (فقط server_audit/watch_log در ابر)، مداخله PIN دوم ۶ رقم ۵ اشتباه→۱۵دقیقه قفل + پنجره ۱۰دقیقه → Grant + بنر + AuditLog. حضانت PIN شخصی (CustodyCredential/masterOverride) — فاز۳ فقط دیدن بدون محاسبه مجدد، نوشتن فقط OWNER با نشست کامل ۵دقیقه (فعلا بسته بماند). هر مدیر یوزر+رمز ≥۱۰ نویسه + device_key + کلید بازیابی OWNER + زنجیره هش server_audit.

**ورود امن:** فروشنده درخواست → کد ۶ رقمی (شناسه جفت‌ساز) روی دسکتاپ → مدیر در PWA چشمی تطبیق + PIN دوم → مجوز موقت (شما نمی‌بینید) → «مدیر تایید کرد — باز شد» — معمولی ۱۰دقیقه حساس ۵دقیقه، ۳دقیقه بدون استفاده خودکار بسته. همه ۳۷ کلید حتی settings باز (ساده).

**خروج:** دکمه بزرگ + خودکار ۱۵دقیقه بی‌کاری → باطل توکن + بنر «مدیر خارج شد».

**قابلیت‌ها:** داشبورد زنده (فروش نقد/کارت/نسیه/چک، برگشت/تعویض، عدد مرجع کشو+کارتخوان، شیفت/حضانت)، گزارشات، قفل هوشمند همه قفل‌ها (۱۰/۵ دقیقه، سیاست قفل ۱۰٪ از راه دور)، نوتیف داخل اپ + تلگرام آپشنال. حضانت فاز۱-۲ فقط خواندنی.

**تکنولوژی:** Fastify+Postgres داخل ایران (WebSocket، FCM ناپایدار)، JWT کوتاه+refresh، PWA، همگام‌سازی فقط SELECT از AuditLog+Snapshot (PRAGMA query_only + worker جدا ۱۲۸MB + backoff ۵دقیقه اگر ۳ شکست + JSONL ۵۰MB حلقه‌ای + idempotent + Heartbeat hash + tailHash + epoch). کد ۶ رقمی راز نیست + امضا HMAC/Ed25519 + nonce/TTL 60s. مبالغ ریال string + تاریخ شمسی. سه کانال Heartbeat/event/pull-on-demand. گام صفر: شمارش دیالوگ‌های رمز خالی + چک WAL + فرمول عدد آبی. push لازم نیست — poll هر ثانیه managerGateStatus+remoteAuth:status.

**ایده‌های برتر:** PANEL_KEYS کاتالوگ خودکار + Number Matching + مجوز notePanelUnlocked explicitOwner + tier دوگانه + AuthLockout نمی‌شکند + Outbox/Heartbeat + blindCount + shift:status + Kill-switch دوگانه + safeStorage Pin + OTP حذف شده + نمای زنده + هشدار مشکوک + Panic.

**امنیت:** HTTPS، bcrypt، AuditLog سه‌گانه، آفلاین fail-safe، فقط قفل‌های موجود، حضانت.

**نقشه راه:** M1 Agent+ابر+PWA (۲ هفته) → M2 مجوز+کد (۱ هفته) → M3 نقش‌ها+دعوت+ACL (۵ روز) → M4 حضانت read-only+لاگ+بنر (۲ روز) → M5 تلگرام/Panic/نمای زنده/هشدار/سلامت (۱ هفته) → M6 سخت‌سازی+بتا (۳-۵ روز).
