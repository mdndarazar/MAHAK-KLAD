# برگه‌ی تشخیص چاپ — فاز ۰ طرح چاپ

> این فایل را **مالک دستگاه** پر می‌کند. ایجنت فقط اسکلت را ساخته است.
> ابزار آزمایش: **تنظیمات ← تب چاپ ← «آزمایش‌گر چاپ (فنی) — اندازه‌ی کاغذ»**.
> هر آزمایش یک برگه‌ی اندازه‌گیری می‌فرستد که رویش خط‌کش، کادر لبه‌ی ۱ میلی‌متری،
> مستطیل مرجع ۵۰×۲۰ و مشخصات همان آزمایش چاپ شده است.

## ۱) مشخصات دستگاه‌ها (قبل از هر آزمایش)

| مورد | مقدار |
|---|---|
| نام و مدل چاپگر فاکتور (Axiom) | |
| اتصال (USB / شبکه / سریال) | |
| نام چاپگر در ویندوز (همان که در فهرست تنظیمات دیده می‌شود) | |
| نام و مدل لیبل‌زن (TSC) | |
| DPI لیبل‌زن (۲۰۳ / ۳۰۰) | |
| درایور (رسمی TSC / Generic / Text Only) | |
| نسخه‌ی ویندوز | |
| اندازه‌ی کاغذ تعریف‌شده در Printing Preferences | |
| نرم‌افزار قبلی با **همین** درایور چاپ می‌کرد؟ | |

## ۲) نتیجه‌ی آزمایش‌ها (راهنمای تصمیم فاز ۱ و ۲)

| آزمایش | چه چیزی فرستاده می‌شود | نتیجه | یادداشت / عکس |
|---|---|---|---|
| **الف** | بدون pageSize (رفتار فعلی برنامه) | | |
| **ب** | pageSize دقیق (میکرون) | | |
| **ج** | ارتفاع خودکار (اندازه‌گیری محتوا) | | |
| **د** | فقط شمارش صفحه‌ی PDF (بدون چاپ) — پیش‌فرض روی اندازه‌ی لیبل ۵۰×۳۰ | تعداد صفحه: … | انتظار: ۱ صفحه |
| **ه** | ردیف دوستونه‌ی لیبل | | |

برای هر برگه‌ی چاپ‌شده این‌ها را یادداشت کنید:

- [ ] کادر لبه‌ی ۱ میلی‌متری کامل چاپ شد؟ (سمتی که بریده/کم است = جهت offset)
- [ ] مستطیل مرجع با خط‌کش چند میلی‌متر درآمد؟ (با **همان عددی که روی خودِ مستطیل چاپ شده** مقایسه کنید — اندازه‌ی مستطیل با اندازه‌ی کاغذ/لیبل عوض می‌شود؛ خطای مجاز ≤ ۱ میلی‌متر)
- [ ] عرض محتوا تا لبه‌ها چقدر فاصله دارد؟
- [ ] برش/کاتر بعد از محتوا افتاد یا وسط آن؟
- [ ] در آزمایش «ه»: هر دو ستون چاپ شد یا یکی خالی ماند؟
- [ ] در آزمایش «د»: تعداد صفحه برابر ۱ بود؟ (بیشتر = فرضیه‌ی «صفحه/لیبل خالی»)
- [ ] متن فارسی و ارقام درست و خواناست؟

## ۳) درخت تصمیم (طبق طرح، بخش ۱۰)

- **ب/ج روی Axiom کادر را دقیق (≤ ۱mm) چاپ کرد** ⇒ موتور Chromium برای فاکتور کافی است
  و فاز ۱ همان مسیر را ادامه می‌دهد.
- **کادر کوچک ماند یا scale شد** ⇒ اول Printing Preferences را بررسی کنید (گزینه‌های
  Scale/Fit و اندازه‌ی پیش‌فرض کاغذ). اگر بعد از آن هم غلط بود ⇒ فاز ۵ (RAW) برای
  فاکتور اولویت می‌گیرد.
- **ه روی TSC بدون لیبل خالی جواب داد** ⇒ مسیر HTML برای لیبل کافی است (فاز ۲).
- **وگرنه** ⇒ TSPL (فاز ۵) مسیر اصلی لیبل می‌شود و فاز ۲ فقط داده/چیدمان را می‌سازد.
- **د عددی بیشتر از ۱ صفحه داد** ⇒ فرضیه‌ی L3 («صفحه‌ی خالی به‌خاطر گردکردن px») تأیید
  می‌شود؛ راه‌حل تعیین‌شده در طرح (ارتفاع ردیف = ارتفاع لیبل منهای ۰٫۰۵ میلی‌متر) در
  فاز ۲ اعمال می‌شود.
- **در حالت ج عددی که برنامه نشان می‌دهد** همان ارتفاع واقعیِ اندازه‌گیری‌شده است
  («۸۰×۵۰٫۴ میلی‌متر» یعنی ارتفاع محتوا ۵۰٫۴mm بوده)؛ همان را اینجا بنویسید و با
  طول برگه‌ی چاپ‌شده مقایسه کنید.

## ۴) موارد فنی حتماً ثبت شود

- نام دقیق چاپگرها همان‌طور که در ویندوز دیده می‌شود (مبنای resolver فاز ۳).
- اگر پیام فارسی خطایی دیدید، **متن کامل پیام** را همان‌جا بنویسید.
- عکس هر برگه (مخصوصاً عکس‌هایی که کنار خط‌کش گرفته شده‌اند).

> ⚠️ هیچ تنظیمی از برنامه را قبل از پر شدن این فایل عوض نکنید؛ ترتیب آزمایش‌ها مهم است
> (الف مبنای مقایسه است).

## ۵) سه مجهول مسیر RAW (فاز ۵) — فقط اگر «دقیق (RAW)» را روشن کردید

> مسیر خام **پیش‌فرض نیست** (پیش‌فرض همه‌ی کاربران `CHROMIUM` می‌ماند). برای روشن‌کردن:
> تنظیمات ← تب چاپ ← بخش پیشرفته ← «روش چاپ» = «دقیق (RAW)». ذخیره فقط وقتی قبول
> می‌شود که **همان روش، چاپ آزمایشی موفق** داده باشد. اگر لیبل روی رول دوستونه
> چاپ می‌کنید این بخش را پر کنید؛ هیچ‌کدام از این سه مورد را ایجنت از روی حدس عوض نمی‌کند.

| # | آزمون | چطور | انتظار | نتیجه | یادداشت |
|---|---|---|---|---|---|
| ۱ | عرض `SIZE` در لیبل دوستونه | «چاپ آزمایشی لیبل» با `columns=2` | دو لیبل کنار هم، بدون لیبل خالی | | اگر فقط یکی چاپ شد یا وسط بریده شد ⇒ بنویسید «SIZE باید عرض یک لیبل باشد» |
| ۲ | قطبیت بیت‌ها | چاپ آزمایشی لیبل؛ نوار شطرنجی و کادر لبه | سیاه‌ها سیاه، سفیدها سفید | | اگر برعکس بود، در تنظیمات پیشرفته گزینه‌ی «معکوس‌کردن سفید/مشکی در RAW» را روشن کنید |
| ۳ | مقدار `DIRECTION` | چاپ آزمایشی لیبل؛ گوشه‌ی نشانه‌دار (کادر ۱mm + خط‌کش) کجاست؟ | گوشه‌ی بالا-چپ فیزیکی | | اگر ۱۸۰ درجه چرخیده بود مقدار `DIRECTION` را در تنظیمات پیشرفته عوض کنید |
| ۴ | DPI چاپگر فاکتور در RAW | چاپ آزمایشی فاکتور (RAW) و اندازه‌ی مستطیل مرجع با خط‌کش | ۵۰×۲۰ میلی‌متر (±۱mm) | | اگر بزرگ/کوچک بود، مقدار «دقت فاکتور RAW» را از تنظیمات پیشرفته عوض کنید |
| ۵ | برش ESC/POS | چاپ آزمایشی فاکتور (RAW) | برگه بعد از محتوا بریده می‌شود | | اگر بریده نشد، مدل دقیق Axiom را بنویسید |

⚠️ اگر آنتی‌ویروس/سیاست سازمانی اجرای اسکریپت چاپ را مسدود کرد، پیام فارسی
«اجرای اسکریپت چاپ توسط سیستم مسدود شد» را همان‌جا بنویسید؛ مسیر Chromium در همان حال
دست‌نخورده کار می‌کند (هیچ fallback خودکاری وجود ندارد و برنامه به‌زور به مسیر دیگر نمی‌رود).
