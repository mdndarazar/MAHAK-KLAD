## نکتهٔ سالم (گیت امنیتی)
پاس کردن چک با مقصد «نقدی صندوق» رد شد: «مقصد با روش پرداخت انتخاب‌شده سازگار نیست؛
برای این روش فقط حساب مدیر ممکن است» — یعنی مقصد پول چک قابل جعل نیست ✅
