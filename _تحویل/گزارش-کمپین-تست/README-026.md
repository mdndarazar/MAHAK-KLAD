## این ۱۰٬۰۰۰تا چی بود؟ (۱۰ قالبِ جدیدِ جهنمی)

| قالب | جهنمش کجاست |
|---|---|
| **hell2-30sale** | ۲۵ قلمی + ۵ اعتبارِ هم‌زمان + برگشتِ ۴ قلم (FEFO مخلوط) |
| **hell2-overpay-card** | اضافه‌پرداختِ کارتیِ ۵۰k — «با اختلافِ دقیق رد» |
| **hell2-return-full-overpay** | برگشتِ کاملِ ۸۰k بدونِ دلیلِ ۳ حرفی → «دلیل اجباریست» — درست رد شد |
| **hell2-ex-unselected** | تعویضِ +۱۰۰k با `UNSELECTED` → «روش انتخاب نشده» |
| **hell2-fefo3** | ۳ اعتبارِ هم‌انقضا → ترتیبِ ورود حاکم |
| **hell2-wholesale200** | ۲۰۰ قلمیِ عمده |
| **hell2-exchange-neg** | ۳۵۰k→۱۵۰k — ۲۰۰k کاهشِ بدهی |
| **hell2-waterfall** | ۱M با ۵ قلم + ۳ اعتبار + چکِ ۲۰۰k + برگشتِ ۴ قلم → آبشار |
| **hell2-cheque-exact** | چکِ ۲۵۰k → ۲۵۰٬۰۰۱ → «اختلاف ۱ ریال» |
| **hell2-idemp-sale** | فروشِ تکراری با یک کلید → replay |

هر قالب ۱۰۰۰ بار با `iter`ِ متفاوت.
